	FIRST DEMO SITE
	"Use the Below Website as a demo site:
https://www.tutorialspoint.com/selenium/practice/text-box.php

This website contains all common form fields and navigations
It is also divided into: Elements, forms, Browser Windows … and so on
Go through the exercises one by one and implement their automation tests

Notes:
- Pick the exercises that we normally face in our projects and avoid wasting your time on tasks that we will not need to automate in our projects
- To benefit from the exercise, extract the locator using your own knowledge and avoid using the browser to extract it for you
- To benefit from the exercise, try not to use any Thread.Sleep
- Try to assert on something to validate that your automation had worked"
